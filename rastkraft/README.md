# Расткрафт

Воксельная песочница на Rust ([macroquad](https://macroquad.rs) + miniquad).
Мир бесконечный: чанки 16×16×128 создаются фоновыми потоками по мере движения
игрока, поэтому при дальности прорисовки 32 на экране одновременно больше 3000 чанков.
Все текстуры, иконки и интерфейс рисуются кодом при запуске, внешних картинок нет.

## Что есть

- **Три биома**: цветущие луга (дубы, берёзы, рощи сакуры, цветы, тыквы),
  знойная пустыня (дюны, кактусы, сухие кусты, пальмы у воды) и снежная тайга
  (ели, папоротники, грибы, замёрзшие озёра, горы со снежными вершинами).
  Кроме них есть океаны с песчаным, гравийным и глиняным дном, а также пляжи.
- **Подземелья**: пещеры-тоннели и большие гроты, лава на глубине, пласты гранита,
  мрамора, туфа и базальта, 8 видов руд по глубинам.
- **Заброшенные шахты**: коридоры с опорными балками, фонарями, паутиной и сундуками.
- **Измерение «Рай»**: парящие острова, золотые деревья, облачные поля, райские кристаллы.
  Портал стоит рядом с точкой появления. Блок портала можно поставить и самому,
  он есть в инвентаре на вкладке «Рай».
- **131 блок**: стройматериалы, 16 цветов шерсти и бетона, цветное стекло, кирпичи,
  руды и блоки металлов, 5 пород дерева, растения, светокамень, фонари, факелы и др.
- **Оружие и инструменты**: мечи, кирки и топоры из 6 материалов
  (дерево, камень, железо, золото, рубин, кристалл).
- **Броня**: шлем, нагрудник, поножи и ботинки из 5 материалов.
  Каждое очко защиты снижает урон на 4%, максимум 80%.
- **Существа**: Мракун (сгорает на солнце), Прыгун (живёт в пещерах), мирный Пушистик.
- **Выживание и Творчество**: здоровье, урон от падения, лавы и кактусов, время добычи
  зависит от инструмента. В Творчестве доступны полёт и мгновенное разрушение.
- Смена дня и ночи, звёзды, солнце и луна, облака, туман, освещение от неба и светящихся
  блоков, мягкие тени в углах.

## Настройки

Дальность прорисовки (2–32 чанка), поле зрения, чувствительность и инверсия мыши,
яркость, размер интерфейса, сложность, туман, облака, плавное освещение,
покачивание камеры, показ FPS. Настройки сохраняются в `rastkraft_settings.txt`
рядом с игрой.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | ходьба |
| Пробел | прыжок, всплыть |
| Ctrl или R | бег |
| Shift | присесть (не упадёшь с края); в полёте — вниз |
| F | полёт (только Творчество) |
| ЛКМ | ударить / ломать (зажать) |
| ПКМ | поставить блок / надеть броню |
| СКМ | взять блок под прицелом |
| 1–9, колесо | выбор ячейки |
| E | инвентарь |
| C | приближение |
| F1 | скрыть интерфейс |
| F3 | отладочная информация |
| Esc | пауза |

## Запуск и сборка

```bash
cargo run --release
```

На Linux нужны пакеты `libx11-dev libxi-dev libgl1-mesa-dev`.

Сборка `.exe` для Windows из Linux:

```bash
rustup target add x86_64-pc-windows-gnu
sudo apt install gcc-mingw-w64-x86-64
cargo build --release --target x86_64-pc-windows-gnu
```

## Устройство кода

| Файл | Что внутри |
|---|---|
| `blocks.rs` | реестр блоков и процедурный атлас текстур |
| `items.rs` | предметы, оружие, броня, их иконки |
| `worldgen.rs` | климат, биомы, рельеф, пещеры, руды, шахты, деревья, Рай |
| `world.rs` | хранение чанков, трассировка луча |
| `mesher.rs` | освещение (BFS) и геометрия чанка |
| `workers.rs` | пул потоков для генерации и построения мешей |
| `render.rs` | отрисовка через miniquad, подгрузка и выгрузка чанков |
| `player.rs`, `mobs.rs` | физика, игрок, существа |
| `ui.rs`, `settings.rs`, `main.rs` | интерфейс, настройки, игровой цикл и экраны |

Для автоматических скриншотов: `RK_SEED=… RK_SHOT=out.png [RK_POSE="x,y,z,yaw,pitch"] [RK_DIM=heaven] [RK_TIME=0.6] [RK_SCREEN=inventory|settings|title]`.
