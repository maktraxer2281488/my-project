# Кубоземье

Воксельная песочница на Rust ([macroquad](https://macroquad.rs)): бесконечное копание и строительство
в мире-острове 256×256×96 блоков. Все текстуры рисуются кодом при запуске (`src/textures.rs`),
поэтому внешних картинок нет.

## Запуск

```bash
cargo run --release
```

Нужен Rust (https://rustup.rs). На Linux также пакеты `libx11-dev libxi-dev libgl1-mesa-dev`.

Переменные окружения:
- `KUBO_SEED=123`: зерно мира (по умолчанию случайное);
- `KUBO_SHOT=shot.png`: сделать скриншот на 4-м кадре и выйти;
- `KUBO_POSE="x,y,z,yaw,pitch"`: поставить камеру (вместе со скриншотом).

### Сборка .exe для Windows (из Linux)

```bash
rustup target add x86_64-pc-windows-gnu
sudo apt install gcc-mingw-w64-x86-64
cargo build --release --target x86_64-pc-windows-gnu
# файл: target/x86_64-pc-windows-gnu/release/kubozemye.exe
```

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | ходьба |
| Пробел | прыжок, всплыть |
| Ctrl или R | бег |
| F | полёт (Пробел — вверх, Shift — вниз) |
| ЛКМ / ПКМ | сломать / поставить блок |
| СКМ | взять блок под прицелом |
| 1–9, колесо | выбор блока |
| F1 | подсказка |
| Esc | освободить мышь |

## Устройство

- `world.rs`: блоки, генерация (шум, горы, снег, пляжи, кристаллическая руда, леса), DDA-трассировка луча.
- `mesh.rs`: меши чанков 16×16 с отсечением скрытых граней и мягким затенением углов (AO), облака.
- `player.rs`: физика игрока, столкновения, плавание, полёт.
- `main.rs`: шейдер с туманом, небо с солнцем, интерфейс, ломание и установка блоков.
