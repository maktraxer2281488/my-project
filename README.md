# Протектор — сайт шиномонтажа

Одностраничный адаптивный сайт без сборки: `index.html`, `styles.css`, `script.js`.

Что есть:
- Hero с анимированной SVG-шиной и счётчиками
- Карточки услуг с подсветкой под курсором
- Калькулятор стоимости (тип авто, радиус R13–R22, набор услуг, RunFlat)
- Блок сезонного хранения с тарифами
- Отзывы, FAQ, схема проезда
- Онлайн-запись: выбор дня и свободного слота, маска телефона, валидация, уведомление

Запуск: откройте `index.html` в браузере (или `npx serve .`).
